# 群英守关

资产项目标识 `hero-td`, 显示名称"群英守关". 项目元数据, SQLite, PNG, YAML 与游戏源代码同处 `projects/hero-td/`, 不与 mmorpg 共享可写数据. 修改显示名称不修改项目标识或浏览器存档键.

## 本地测试

启动 Asset Forge 后, 选择"群英守关", 在"新建项目 / 修改名称"后点击"测试". 按钮打开 `/games/hero-td/index.html?project=hero-td` 独立窗口. 不同项目使用不同窗口名称. 浏览器可能按设置打开为新标签页; 弹窗被拦截时编辑器会提示允许本站弹窗.

项目游戏入口约定为 `projects/<id>/game/index.html`. `GET /api/projects/<id>/game` 返回 `{available, url}`. 未提供入口时 `available:false, url:null`, 入口损坏和目录链接问题明确报错. 文件读取只允许 game 子树中 HTML, MJS, CSS, JSON, PNG, SVG, 不开放项目数据库. 项目代码在本机服务同源执行, 此约定不是不可信脚本沙箱.

游戏通过当前项目的 `/workspace` 和 `/images?file=...` API 读取已保存数据, 与编辑器共用 `/editor/hero-runtime.mjs`. 测试入口阻止未保存修改, 待恢复草稿及保存中状态. 编辑器保存不会热更新已开始的对局, 修改配置后重新打开或刷新游戏.

## 操作与规则

- 固定 5 路 x 8 列, 我方朝右, 敌人从右往左. 同名英雄可以重复部署为英灵分身.
- 鼠标选牌后点击空格部署, 悬停显示向前射程. 数字键 1-5 选牌, D 切换撤除, 空格暂停, Esc 清空选择. 棋盘获得焦点后可用方向键选格, Enter 部署.
- 所有防守单位(含聚灵阵)占格并阻挡敌人, 阵亡或撤除后格子空出. 撤除不退款, 再次部署重新付费.
- 灵气按时间自然恢复, 聚灵阵按周期额外产出. 黄忠远程单体, 张飞高生命近战, 关羽近距群攻, 诸葛亮远程减速. 近战只能命中前方射程内敌人.
- 出兵按预定时间推进, 不等待上一批消灭. 所有预定敌人出场且场上敌人清空后获胜, 预计时长不是强制结束时间. 每漏一个敌人扣 1 点城门耐久, 从 3 点降到 0 失败.
- 第一关约 2 分钟, 后两关约 3-5 分钟. 第一关通关解锁关羽, 第二关解锁诸葛亮. 不提供永久攻击或生命加成.
- 页面隐藏自动暂停. 每次重开关卡重置战场, 灵气和城门, 不继承上关资源.

## 命中与打击反馈

本项目显式使用 `heroMotion` v2. 攻击默认蓄力 100ms, 出手 50ms, 收招 150ms, 两次起手间隔仍由资产表决定. 时序由共享运行时解析后注入战斗模型, 以 50ms 固定步长推进. 短攻击周期会压缩动作, 最短周期允许同一步出手. 模型不通过动画回调或浏览器定时器结算伤害.

近战在出手结束时结算; 箭矢和法术弹到达才结算. 箭矢每秒 32 格, 法术弹每秒 24 格, 飞行时间向上取整至模拟步长并限制在 50-300ms. 单体起手锁定目标, 出手时检查存活, 同路和射程, 落空不返还周期. 关羽出手时确定本路范围内全部目标. 来源在出手前死亡或撤除则取消; 已发射弹体使用出手时快照继续飞行, 不转移到新目标. 目标死亡或漏怪使弹体失效.

每次有效英雄出手消耗一次随机判定, 群攻共用结果. `crit_chance_percent` 可选, 范围 0-100, 缺失或空值为 0. 四位英雄保存为 20, 聚灵阵为 0, 敌人不暴击, 倍率固定为 2. 基础伤害保持黄忠 20, 张飞 8, 关羽 45, 诸葛亮 12. 飘字显示命中事件的结算伤害, 包含溢出部分, 生命最低为 0; 不在表现层翻倍或按数字大小猜测暴击.

命中事件自带逻辑时间, 来源与目标快照, 伤害, 暴击和受力方向. 同一步先移动并判定接触, 收集到期出手, 再按攻击序号结算命中, 最后清理死亡和判定胜负. 表现层依次推进事件之间的视觉时间, 不把同一帧内不同模拟步的命中都放在帧末.

普通命中闪白, 沿受力方向后缩并压缩回弹; 暴击更亮, 后缩和形变更明显, 数字更大并使用金橙色. 重甲后缩减半. 后缩在世界方向上叠加绘制, 不写回位置, 不改变阻挡或射程. 连击不累积漂移, 普通受击不覆盖攻击动作. 关羽命中或暴击局部停顿最多 50ms, 不暂停模型或延迟下一次出手. 最后一击保留死亡快照, 死亡约 250ms, 飘字最多 750ms; 模型完结即保存通关, 表现层继续收尾再显示结算. 收尾支持暂停和继续, 此时重开也不会丢失已取得的通关记录.

飘字按目标左右交替展开并加描边, 避免普通数字与暴击标签互相覆盖; 字形边界限制在画布内.

音效用 Web Audio 合成出手, 普通命中, 重甲命中, 暴击和死亡短音, 无外部音频下载. 点击出征时初始化或恢复音频. 同类声音在 50ms 内合并, 同时最多 8 组, 单组低增益. "音效"按钮按项目保存开关, 暂停, 后台或重开立即停止余音. 声卡不可用或偏好无法保存时显示提示, 不阻止战斗.

## 资产表

| 分类 | ID 范围 | 职责 |
| --- | --- | --- |
| td_units / 防守单位 | 1001-1999 | 部署费用, 生命, 攻击, 暴击率, 产灵气, 减速, 图片与解锁条件 |
| td_enemies / 进攻敌人 | 2001-2999 | 生命, 攻击, 移动速度与图片 |
| td_levels / 闯关配置 | 3001-3999 | 关卡名称, 提示, 预计时长, 初始灵气与自然恢复 |
| td_spawns / 出兵波次 | 4001-9999 | 关卡引用, 路线, 敌人引用, 出兵时间, 数量与间隔 |

单位职责通过 `td_role` 枚举维护: 1 产灵气, 2 远程单攻, 3 近战阻挡, 4 近战群攻, 5 远程减速. `undefined=0` 为编辑器保留值, 不能用作有效战斗职责.

沿用编辑器的 uint32, 不引入浮点字段:

- `*_ms`: 毫秒, 游戏边界统一转换成秒.
- `range_percent`: 100 代表 1 格, 800 代表 8 格. 攻击英雄至少 45, 能覆盖敌人的停靠位置.
- `speed_percent`: 100 代表每秒前进 1 格.
- `slow_percent`: 减速后的剩余速度百分比, 如 50 为半速. 减速职责必须在 1-99 之间.
- `lane`: 0-4, 从上到下. `time_ms` 是首名敌人出现时间, 后续按 `spacing_ms` 展开.
- `unlock_level`: 0 表示初始可用, 其他值为必须先通关的关卡 ID. 关卡按 ID 升序解锁.

游戏加载时检查 ID, 数值范围, PNG 引用, 解锁与出兵引用, 空波次和末次出兵时间. 任何配置错误都会阻止开局并展示原因. 源数据只以 SQLite 中已保存的资产表为准, 不从 YAML 或另一份硬编码初始配置兜底.

英雄与敌人头像均为 256 x 256 透明 PNG, 法阵和装备为 128 x 128 透明 PNG. 英雄头像仅放在 `assets/heroes/` 直接子级, 敌人放在 `assets/enemies/`, 其余为 `assets/icons/`. 头像和武器的挂点及微动作完全使用同项目已保存的 `heroMotion` 和共享运行时. 战场位移, 弹道, 血条与命中效果由游戏界面负责.

## 存档

浏览器键包含项目标识, 保存版本号和已通关关卡 ID, 不保存正在进行的战斗. 关卡解锁必须连续. 非法或无法读取的原存档保持原样, 页面显示提示并仅在内存推进, 不静默覆盖. 写入失败明确提示新增进度不会跨页面保留.

存档依赖当前浏览器与站点来源. 本地测试和公开站点不会自动共享进度, 清除网站数据会清除存档.

## 静态发布文件

```powershell
node scripts/export-project-game.mjs hero-td output/hero-td-web
```

输出目录必须不存在, 父目录必须存在, 且不能放入 projects 树. 脚本读取已保存数据, 先校验所有来源并建立快照, 再写同父目录的临时文件夹, 最后重命名成目标. 不覆盖已有导出. 失败时只清理本次临时目录, 源数据保持不变.

静态包含游戏 HTML/MJS/CSS, `workspace.json`(仅 workspace 与 project), 被引用的 PNG 和同版本 `hero-runtime.mjs`. 不包含数据库, 账号信息或本机绝对路径. 使用 HTTP 静态服务器或任意静态托管发布目录内容, 入口为 `index.html`, 不附加 `project` 查询参数. 不支持直接双击 file:// 页面加载 ESM 与 JSON.

编辑器 YAML 导出与静态发布包是不同用途: 前者供配置消费方读取, 后者是一份可直接部署的单机网页. 本命令不自动上传, 建立账号或发布站点.
