# 创建角色

默认目标是图标级简化的胶囊小人. 用少量几何形和身份符号表达人物, 保持同系列的一致性. 用户明确指定的新风格优先; 单纯更换题材不改变本技能的造型与渲染规则.

## 视觉参考

生成前先实际查看相关参考图, 并选择 1-2 张作为图像工具的风格参考输入. 路径相对于本技能目录解析, 不依赖临时文件或上次对话.

- [legend.png](references/legend.png): 国王, 小丑, 公主, 火枪手. 查看头身连接, 黑点眼和单一道具的表达.
- [workers.png](references/workers.png): 农夫, 矿工, 铁匠, 弓手. 查看服装与身体的合并, 椭圆手和豆粒脚.
- [rare.png](references/rare.png): 法师, 守卫, 盗贼, 猎人. 查看头饰, 武器与大色块如何区分职业.
- [epic.png](references/epic.png): 骑士, 炼金术师, 女巫, 厨师. 查看极简面部和少量轮廓变化.

这些图是用户提供的原作风格参考. 仅提取视觉语言, 为新题材设计新造型. 卡框, 稀有度底色和文字属于展示包装, 用户未要求时不带入角色图. 不把之前生成的精细三国武将图作为该风格的基准.

## 设计关键词

中文: 胶囊小人, 超短身, 头身紧连, 粗黑等宽描边, 圆角几何造型, 黑点眼, 极简嘴, 无鼻或极简鼻, 椭圆手, 豆粒脚, 大面积纯色色块, 极少阴影, 小块高光, 单一道具识别, 图标级简化.

英文: capsule-shaped cartoon character, ultra-compact proportions, head joined directly to body, bold uniform black outlines, rounded geometric shapes, tiny black dot eyes, minimal mouth, no visible nose, oval hands, tiny bean-shaped feet, large flat color fills, minimal shading, tiny highlight patches, single signature prop, readable game icon.

避免仅用 "chibi", "cute warrior", "collectible hero" 描述风格. 提示词必须展开身体结构, 线条, 五官和色块规则, 避免模型自行补成精细 Q 版立绘.

## 固定造型规则

以下比例是便于制作的近似默认值, 不是对原作的精确测量. 实际参考图的结构优先于数字.

| 维度 | 默认规则 |
| --- | --- |
| 比例 | 不含帽子, 羽毛和武器时约 1.5-2 头身的视觉感受. 头直接连接短小身体, 不突出脖子, 腰线和长腿. |
| 身体 | 用一个短胶囊或圆角梯形表示躯干. 衣服与身体合成大色块, 允许一条腰带或简单衣领说明身份. |
| 面部 | 小黑点或短竖线眼睛, 无虹膜和复杂眼白. 嘴是短线或小弧线, 鼻子默认省略; 胡须与头盔可遮住面部. 眉毛只在身份或表情需要时添加. |
| 头发与胡须 | 用 1-3 个连贯色块构成整片发型或胡须. 轮廓负责识别, 不画发丝, 发束高光或分层毛发. |
| 手脚 | 手是一小块椭圆或圆角形, 不展开手指, 握拳结构和肌肉. 脚是身体底部两个小豆粒形, 不画长小腿与大靴筒. |
| 线条 | 纯黑或视觉上接近纯黑的粗线, 端点与连接处圆润, 同图线宽相对统一. 内部线只保留色块分界和必要符号. |
| 色彩 | 少量清楚的大色块, 通常约 3-5 个主要色组, 肤色与中性色按需要补充. 明快饱和, 装饰色不切碎主体. |
| 明暗 | 平面填色为主, 可有极轻的边缘阴影和少量小块高光. 不用多层体积塑造, 皮肤渐变, 金属强反光或布料褶皱提高精细度. |
| 服装与护甲 | 将盔甲压缩为一个胸甲色块, 一条边或一枚扣件. 不拆成完整肩甲, 臂甲, 裙甲, 护膝和靴甲系统. |
| 道具 | 一个主要身份道具, 保留它最易识别的外形. 武器厚实简洁, 完整入画, 不遮住主要五官, 不增加雕花和零碎附件. |
| 视角与姿势 | 平面正面或轻微侧向, 少量耳朵位置变化即可暗示朝向. 紧凑站姿, 用道具方向和简洁手势表现个性, 避免复杂透视与动态人体结构. |

## 身份差异与批量设计

先统一头身结构, 黑线粗细, 眼睛画法, 手脚形式, 色块密度和画面占比. 每个角色优先使用一个头部特征, 一个主道具和一组服装颜色区分身份. 允许题材必需的辅助特征, 不为凑差异堆叠装饰.

保持角色之间真正的剪影差异, 但不要为了变化而展开肢体结构. 可改变帽顶, 发型整体轮廓, 胡须长度, 胶囊身体的宽窄和道具形状. 性格通过极少量表情和道具姿态表达.

批量可先列简洁角色表: 人物, 头部特征, 主道具, 主色, 必要辅助特征. 随后直接完成已授权任务, 不将角色表当作等待确认的关卡.

三国题材可按下列方向抽象, 具体以用户要求为准:

| 人物 | 核心识别符号 |
| --- | --- |
| 曹操 | 简化冠帽, 短须色块, 紫衣, 短剑. |
| 吕布 | 两根简化翎羽, 红衣, 方天画戟. |
| 关羽 | 绿头巾, 红脸, 一整块长须, 偃月刀. |
| 张飞 | 圆宽身体, 一整片炸须轮廓, 黑衣, 蛇矛. |
| 赵云 | 简化银盔与白缨, 蓝白衣, 长枪. |

## 执行与交付

- 所有角色图片统一交付为 PNG 格式, 默认使用带真实 alpha 通道的透明底 PNG, 文件扩展名使用 `.png`. 向图像工具明确要求 PNG 和透明背景, 保存后检查实际格式与背景透明度, 不以修改后缀代替格式转换.
- 最终交付画布固定为 256 x 256 像素, 包含角色, 随身道具及透明边距. 生成工具无法直接输出该尺寸时, 使用本机已有的图像缩放能力将结果等比高质量缩放并居中放入透明画布, 保留 alpha 通道; 不拉伸变形, 不裁掉头饰, 手脚或武器. 保存后读取实际宽高确认, 不只在提示词中声明尺寸.
- 判断用户要文字设定, 提示词还是图片. 本技能中直接要求创建具体角色且没有限定文字时, 默认生成图片; 仅要求分析或更新技能时不出图.
- 沿用用户指定的题材和人物. 将题材特征压缩进现有胶囊结构, 不因为是历史武将就自动添加精细铠甲或写实人体. 题材未定且不影响任务时默认轻奇幻.
- 使用当前 AI 工具可用的图像生成或编辑能力生成位图; 若环境提供 imagegen 技能, 按其说明操作, 但不将该技能或某个专用工具作为跨工具使用的前提. 查看参考图后实际将其作为风格参考传入, 明确它只约束造型和渲染, 不复制原角色或卡片布局. 缺少出图能力或无法传入参考图时, 如实交付提示词及需附带的参考图路径, 说明图片未生成. 仅请求文字设定或提示词时无需出图能力.
- 默认每张只含一个完整角色. 用户列出多个角色时, 默认每人一张独立文件; 只有明确要求合图或阵容展示时才放在同一画面. 不用多人合图替代独立资产.
- 默认只保留角色及其随身道具, 无背景, 无地面阴影, 无文字, 无卡框, 保留完整头饰, 手脚, 道具及透明外边距. 角色之外的区域应完全透明, 不使用白底, 黑底或绘制的棋盘格模拟透明. 只有用户明确要求展示背景或地面投影时才添加.
- 批量每次生成都带上相同的风格规则和原始参考, 不只写 "同上". 已生成图经实际检查符合规则后才可用作补充参考, 不让偏离目标的首图影响整批.
- 优先检查头身结构, 眼睛, 黑线和简化程度. 即使人物身份准确, 只要出现精细 Q 版立绘特征, 仍需修正造型和渲染; 不仅继续删纹样.
- 输出图片按用户目标保存, 保留对应提示词. 批量中断时说明已完成和未完成角色, 保留成功结果.

## 提示词模板

将花括号替换为明确设计, 不把占位符直接交给生成工具. 需要英文时采用同一组视觉约束, 不改成泛泛的动漫英雄提示词.

```text
生成一张独立的{人物/职业}角色图, 题材为{题材}, 画面只有一个人物.
输入图片的用途: 仅参考其胶囊造型, 极简面部, 粗黑描边和大色块,
不复制参考角色, 文字, 稀有度卡框或排版.

角色识别: {一个头部特征}, {一个主道具}, {必要辅助符号}.
颜色分布: {肤色}, {头部主色}, {身体主色}, {道具主色及少量点缀色}.

统一造型: 图标级简化的胶囊小人, 约{默认 1.5-2}头身的视觉感受,
头直接连接短胶囊身体, 几乎无脖子, 无展开的腰腿结构,
小黑点或短竖线眼睛, 极小嘴, 默认无鼻,
头发和胡须是一整片简单色块, 椭圆手无手指, 豆粒脚.
服装与身体合成少量大色块, 道具保留最易识别的外形.
统一渲染: 圆角连接的粗黑等宽描边, 大面积平面填色,
极少边缘阴影和少量小块高光, 内部线条很少,
明快, 俏皮, 适合缩略图的二维卡通游戏角色.
构图: {正面或轻微侧向}, 完整全身, 完整道具, 四周留白,
真实透明背景, 仅保留角色和随身道具, 无地面阴影, 无文字, 无卡框,
最终交付为 256 x 256 像素画布, 带 alpha 通道的 PNG,
完整角色和道具居中并保留透明边距; 只有用户明确要求时才改为指定展示背景.

避免: 大眼动漫脸, 虹膜, 立体鼻子, 复杂眉眼,
可见脖子, 长腿, 手指, 大靴筒, 分层护甲,
雕花金边, 发丝, 多层明暗, 渐变皮肤, 写实金属与布料,
三维渲染, 精细 Q 版武将立绘, 复杂动作或场景.
```

## 出图检查

先核对原始参考与结果的四个重点: 胶囊头身结构, 小黑点眼, 粗黑等宽线, 大色块与极少阴影. 再检查身份符号与交付完整性.

- 缩小观看时, 角色是否仍像紧凑的小图标, 主道具是否可读? 只有文字评估时不声称实际做过缩图验证.
- 是否出现细腰长腿, 复杂握拳, 多层铠甲, 发束明暗或精细材质? 出现这些特征时先回到基础形状重做.
- 同批是否使用一致的线宽, 面部与手脚形式? 是否只换颜色而没有身份差异?
- 一张图是否只有所需人物, 头饰与道具是否完整, 是否有误加文字, 多余肢体或错误握持?
- 默认交付的 PNG 是否包含 alpha 通道, 角色外部是否真正透明, 是否残留白底, 背景色或地面阴影? 检查实际像素透明度后再宣称透明底, 不只检查扩展名或透明选项.
- 读取最终 PNG 的实际宽高, 确认严格等于 256 x 256 像素, 缩放后角色与道具完整, 无拉伸变形, 透明边距仍然保留.
- 仅在实际检查后报告结果. 不承诺未验证的透明度, 分层结构或动画可用性.
