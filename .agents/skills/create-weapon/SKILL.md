# 创建武器

制作独立的冷兵器游戏图标, 每件一张完整武器. 使用 [create-icon 的共享规范](../create-icon/SKILL.md) 中的造型, 渲染, 图像工具和文件交付规则; 本技能补充武器结构与原图朝向. 读取共享规范时不再次转交技能. 仅请求技能创建, 分析或提示词时不生成图片.

## 风格与参考

生成前实际查看 [items-overview.png](../create-icon/references/items-overview.png), 以其粗黑描边, 圆润厚实的几何轮廓, 鲜亮平面色块, 少量块状高光和极少阴影为基准. 按需要查看 [basic-symbols.png](../create-icon/references/basic-symbols.png) 中的单剑与交叉武器, 作为结构简化的补充参考.

将已查看的相关图片实际传入图像工具并注明风格用途. 原始参考只约束造型与渲染, 不沿用其中武器的朝向, 灰框, 槽位, 锁头或图集排版. 参考图由 create-icon 统一维护, 不复制第二套. 不把精细武器插画, 三维装备或之前朝向不符的生成图作为基准.

## 方向与结构

以下方向以未镜像的 PNG 画布为准, 原点在左上, X 向右, Y 向下, 不按持握者的左右解释. 主轴是连接武器两端的轴线, 不要求弯曲刃口或弓身本身成为直线.

| 类型 | 原图方向与识别结构 |
| --- | --- |
| 刀, 剑 | 主轴从左上到右下. 刀头或剑尖在左上, 握柄和柄尾在右下. 单刃刀开刃侧朝画布左下, 刀背位于相对右上侧; 双刃剑保留对称结构. |
| 斧, 锤 | 斧头或锤头在左上, 柄尾在右下. 单刃斧的刃口朝左下, 双刃斧保留对称结构. 锤头保留锤的剪影, 不为符合刃口规则画成刀斧. |
| 枪矛, 戟, 长柄刀 | 主轴从左上到右下, 尖端或兵器头在左上, 柄尾在右下. 保留足够的长柄比例和独特头部结构. 单刃长柄刀的开刃侧同样朝左下. |
| 弓 | 两个弓梢端点沿左上到右下排列, 弓身向画布左下凸出. 弓弦连接左上弓梢和右下弓梢, 位于弓身的相对右上侧. 默认自然弦态, 不拉弓, 不搭箭. 弦所在一侧不代表弓的发射方向. |
| 弩 | 主轴从左上到右下, 发射前端指向左上, 托柄朝右下. 弓臂横跨主轴, 保留弩身, 弓臂与弦的必要结构, 默认不搭箭. 不套用单弓的凸出侧规则改变弩的结构. |

- 刃口侧与刀头位置是两个独立要求, 不能只满足其一. 不画成左下刀头与右上柄尾的另一条对角线, 也不颠倒左上与右下的前后端.
- 武器完整入画, 主体视觉居中, 各边保留透明边距, 不把角点理解为必须贴住画布边缘. 长兵器可适度图标化缩短, 不裁掉柄尾, 弓梢或刃尖, 不用非等比拉伸填满画布.
- 保留各类型最关键的剪影和 1-2 个身份特征. 例如青龙偃月刀使用宽厚偃月刀腹, 长柄和简化龙首刀颈, 不以细长弯刀代替; 装饰不发展成复杂龙鳞, 雕花或纹理.
- 默认只画一件武器, 不附带人物, 手, 手臂, 鞘, 展示架, 文字, 背景或地面投影. 不因兵器属于某位英雄而加入该人物头像.
- 用户明确要求不同朝向, 搭箭或动作状态时, 只为该次请求替换相关默认约束, 同步修改提示词与检查项, 不同时保留互相矛盾的要求. 法杖和火器不套用本技能的冷兵器方向模板.

## 生成与保存

- 中文命名: 新建武器的交付名称和 PNG 文件名直接使用中文武器名, 例如 `青龙偃月刀.png`, `铁剑.png`, 不默认使用拼音或英文名. 同名文件已存在且未明确要求覆盖时, 使用 `青龙偃月刀-2.png` 等版本名. 提示词记录和交付链接必须引用实际中文文件名; 文件名不代表要在图片中绘制文字. 已有文件及资产引用不因本规则自动改名.
- 沿用 create-icon 的实际出图与透明背景流程, 每件最终交付严格为 128 x 128 PNG, 保留真实 alpha 通道. 工具不能直出尺寸时用已有图像处理能力等比缩放并居中放入透明画布, 不更改武器形状来填满画布.
- 用户未要求替换时使用新文件名, 不覆盖已有武器. 沿用用户指定目录; 本项目建议放入当前项目 `projects/<项目标识>/assets/icons/weapons/`. 不因技能更新而重新生成或旋转已有图片.
- 保存每件武器的实际完整提示词及使用的参考图路径, 项目内参考使用可从仓库定位的相对路径. 批量每件独立成图, 每次传入完整共同约束和必要参考, 不只写 "同上".
- PNG 只包含武器, 不包含握持点或动作数据. 使用方继续以既有固定挂点组合头像和武器, 向右时整体水平镜像. 不自动修改挂点, 运行时代码, heroMotion 配置或资产引用.
- 工具无出图能力或不能传入参考图时, 只交付完整提示词和参考图路径并说明图片未生成. 中断时保留合格结果, 列明完成项与未完成项.

## 提示词模板

每次将下面的共同约束与一个对应类型模板完整拼接, 替换所有占位内容后交给图像工具. 输入图需明确标记为风格参考, 类型模板中的方向优先于参考图的布局.

共同约束:

```text
创建一张独立的{武器名称}游戏装备图标, 只画一件完整武器, 不附带人或手.
风格参考: {已查看并实际传入的共享参考图}; 仅提取造型和渲染, 不沿用朝向或界面布局.
识别特征: {核心武器结构及必要的 1-2 个身份特征}. 配色: {少量明确主色}.
圆润厚实的二维卡通几何轮廓, 圆角连接的粗黑描边, 鲜亮平面大色块,
少量简单块状高光, 极少阴影, 内部结构简化, 缩小后剪影清楚.
以下方向均以画布为准: 左上为原点, X 向右, Y 向下.
主体居中, 完整入画, 四周保留透明边距, 最终交付 128 x 128 像素真实透明 PNG.
无人物, 无手臂, 无鞘, 无展示架, 无文字, 无边框, 无场景或地面投影.
避免复杂渐变, 写实反射, 三维渲染, 密集纹理, 裁切或非等比拉伸.
不画白底, 黑底或透明棋盘格. 保留主体内部本来不透明的白色刀刃与高光.
```

近战武器方向:

```text
武器主轴从画布左上到右下. {刀头/剑尖/斧头/锤头/矛尖/戟头}在左上,
握柄或柄尾在右下. {单刃刀或斧: 开刃侧朝画布左下, 背侧位于相对右上侧;
双刃武器: 保留对称结构; 无刃武器: 保留自身头部结构, 不添加刃口. 只保留适用的一项.}
完整保留兵器头和柄尾, 不倒置, 不改成左下到右上的对角线.
```

弓方向:

```text
一把自然弦态的弓, 两个弓梢沿画布左上到右下排列.
弓身向画布左下凸出, 弓弦连接左上与右下的弓梢,
弦位于弓身的相对右上侧. 两端与弦都完整可见.
默认不拉弓, 不搭箭, 不添加箭袋, 不画成弩.
```

弩方向:

```text
一把未搭箭的弩, 主轴从画布左上到右下.
发射前端指向左上, 托柄朝右下, 弓臂横跨主轴.
保留清楚简洁的弩身, 弓臂和弦, 不画成单弓, 不额外添加箭支或箭袋.
```

## 出图检查

- 对照原始参考检查粗黑描边, 圆润几何和色块简化程度, 实际以 128 x 128 尺寸查看识别结构与长柄是否可读.
- 核对未镜像的原图: 主轴是否左上到右下, 近战头部或弩的前端是否在左上, 柄尾是否在右下? 单刃刀斧的开刃侧是否朝左下?
- 弓的弓身是否向左下凸出, 弦是否连接两个弓梢并位于相对右上侧, 是否保持默认无箭且未拉弓? 弩是否保留横跨主轴的弓臂, 没有误套弓的侧向规则?
- 主体是否完整, 四周是否留有透明边距? 是否误加人物, 手, 鞘, 灰框, 文字或背景?
- 实际读取最终文件格式与宽高, 确认 PNG, 128 x 128. 检查主体外真实 alpha 为 0 的透明像素, 在浅色与深色背景查看边缘和主体内部, 不只检查扩展名或四角.
- 方向错误时按图像生成或编辑流程修正并复检. 仅旋转到主轴正确不代表刃口侧或弓身侧正确, 仅水平镜像也不保证满足全部方向约束.
- 图片与实际提示词一一对应. 只报告实际完成的检查; 仅交付技能或提示词时不声称已验证图片方向, 透明度或动画效果.
